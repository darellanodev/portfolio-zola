**Cave Drop** is a 2D physics-based game with vector graphics, originally developed with Processing for desktop and Android. Now I'm porting it to the web with JavaScript and Matter.js. Place bars wisely to guide the balls to their final destination.

![Cave drop screenshots](./screenshots.png)
