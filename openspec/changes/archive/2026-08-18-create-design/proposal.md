## Why

Two temporary text files (`tmp-prompt.txt` and `tmp-prompt-light-mode.txt`) contain the design specifications for the site's background gradient system (dark mode "Cosmic Dust" and light mode "Cotton Candy"). These are ephemeral files that should be replaced with a permanent `DESIGN.md` at the project root, capturing the design intent, architectural rules, and implementation deviations.

## What Changes

- Create `DESIGN.md` at project root with gradient theme specs and architectural rules
- Delete `tmp-prompt.txt` (dark mode spec)
- Delete `tmp-prompt-light-mode.txt` (light mode spec)
